## 2. Accuracy of the proxy (what Phase 2 must model properly)

| Element | Phase 1 proxy | Phase 2 production need |
| --- | --- | --- |
| Shingles | Roof: textured layer with course lines at the true 5⅝″ exposure. Panel: real overlapping course slabs (13¼″ × 5⅝″ geometry). | Laminated profile (two-layer "dragon tooth"), granule normal maps, accurate Oyster Shell blend from JM photos or samples |
| Hip/ridge caps | Folded strips at 5⅝″ steps; the last ridge cap is the lock piece | Real cap profile; the product JM uses (Q-R2) |
| Ridge vent | Simple tent over a deck slot | The exhaust JM actually installs on hip roofs (Q-R4) |
| Drip edge | L-profile, flange under the underlayment at the eave | Real profile (JM paints flashing white, per their post) |
| Underlayment | Graphite slab, 6 mm (exaggerated) | Product type: felt or synthetic (Q-R2); lap lines |
| Deck | OSB-tan slab, 30 mm (exaggerated) | Panel seams, edge clips if used |
| Starter, nails, sealant | Starter slab in the panel. Nails and sealant are shown as overlays only (hidden by real shingles). | Nail count per JM (Q-R3), sealant strip geometry for the cutaway |
| Step and kick-out flashing | **Not modeled** (no porch joint in the proxy) | Add the porch-to-wall joint from Phase 0 02 §2 |
| Vent boot | Cone boot + flange on top of the courses | Flange shingled in correctly (upper courses over it) |
| Gutter / soffit vent | U-channel gutter, continuous soffit vent strip | JM's gutter profile and size (Q-R5) |
| House | Generic stucco box, 4 windows, door | Massing from a JM reference job with the homeowner's consent (Q-R7), never a recognizable address |
| Weather | Light, wetness and SVG overlays | Optional rendered water sheeting along the true lap paths, and dust in the wind state, still with no storm spectacle |
