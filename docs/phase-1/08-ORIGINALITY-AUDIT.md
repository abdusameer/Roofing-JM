# 08 · Originality Audit

Checked against the Phase 1 originality rules and Phase 0 03 §5. Evidence: the screenshots in `docs/phase-1/screenshots/`.

## 1. The rules

| Rule | Finding | Pass |
| --- | --- | --- |
| Not an Apple-style product explosion | The house never leaves. Layers lift only vertically, along their real stacking direction, over a lit house on a plaster table, not into a black void. There is no spin, and no hero object floating alone. | ✓ |
| Not an automotive durability commercial | No speed, no slow motion, no heroic music or grading. The weather is quiet light and diagrammatic lines, labeled as illustration, not a test. | ✓ |
| Not a contractor template with weather effects | No drone-house hero, no navy/yellow palette, no badge wall, no financing banner, no stock crew, no before/after slider. The page's job is explanation (Phase 0 found 0 of 13 local competitors do this). | ✓ |
| Not a blue-and-orange storm montage | One redline accent. Weather colors appear only as thin functional lines in their own chapter. No lightning, no damage. | ✓ |
| Not a collection of unrelated 3D tricks | One medium, one scene, one camera rig. The camera moves twice: in to the panel, and out to the house. | ✓ |
| No copied camera path, spacing, lighting, timing, type or transitions | Choreography derives from construction logic: lift order top-down (removal), settle order bottom-up (installation), panel out along the roof normal. Lighting follows the LA calendar. Type: Archivo condensed + Plex Mono, set to the page's own grid. | ✓ |
| Closest existing artefact: Owens Corning's "Total Protection Roofing System" diagram (Phase 0 A4) | Ours is not a numbered product catalog. It is a cut from one real-type house, ordered by job, with the panel physically traveling. No OC imagery or marks; trademark notice in the footer. | ✓ |

## 2. The avoid list

| Avoid | Present? |
| --- | --- |
| Generic drone-house opening | No: a modeled bungalow, three-quarter view |
| Fake rain on the camera lens | No: rain falls on the panel and runs along the courses |
| Flying shingles, floating debris | No: courses stay down, which is the lesson. Wind "dust" is a sparse dotted line that follows the airflow. |
| Badge walls | No: dated text facts only |
| Stock construction crews | No people anywhere (and no ladders) |
| Decorative gauges | None |
| Unsupported statistics | None. The only figure is the manufacturer's CRRC listing ID, sourced. |
| Constant camera orbiting | None |

## 3. "Could this sell a car, shoe or jacket?" (per chapter)

| Chapter | Roof-only mechanic the visuals depend on | Survives the swap? |
| --- | --- | --- |
| Anatomy | Nested hip-roof layers; a drip edge under the underlayment at the eave; an attic air path from soffit to ridge | No |
| Panel | An eave-corner cutaway with a stepped deck/underlayment/shingle reveal, gutter and soffit | No |
| Heat | Reflective granules; sun-activated sealant under each course; attic ventilation | No |
| Wind | The sealed bond holds courses flat; a nailing zone hidden under the next course; the starter edge at the eave | No |
| Rain | Water crossing headlaps, splitting around a pipe boot, leaving over the drip edge into a gutter | No |
| Reassembly | Installation order; the last ridge cap locks | No |

Replacing the roof with a jacket would break every chapter, so the idea is specific to roofing.

## 4. Residual risks for Phase 2

- **Photoreal upgrade drift:** heavier VFX could slide toward spectacle. Keep water on the true lap paths only, and keep the house in shot.
- **Copy drift:** "Built for everything." is the one line that sounds like a durability commercial. Resolve it with counsel before launch (01 §6).
- **Brand integration:** when JM's blue/red/yellow logo arrives, keep it inside the logo so the page doesn't drift back to the category palette.
